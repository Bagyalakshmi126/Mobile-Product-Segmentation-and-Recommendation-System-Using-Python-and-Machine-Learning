# Mobile-Product-Segmentation-and-Recommendation-System-Using-Python-and-Machine-Learning
Data science project analyzing smartphone markets through clustering models, visual analytics, and an optimized similarity recommendation engine.

**📱 Smartphone Market Analytics & Recommender System**

An easy-to-use interactive dashboard built with Python, Streamlit, and Plotly. This project uses Machine Learning to group smartphones into 4 distinct market segments and recommends similar phones based on specs and user ratings.

**🎯 1. Project Goal**

The main objective of this project is to help users and businesses analyze the smartphone market easily:

Market Segmentation: Group smartphones by price, performance, camera quality, and rating.

Smart Recommendations: Instantly suggest similar phones based on selected feature specifications.

Visual Insights: Provide simple interactive charts to highlight market trends and price-to-performance sweet spots.

**📦 2. Dataset Overview**

Main Dataset: cleaned_smartphones.csv

Features Included:

brand: Phone manufacturer (Apple, Samsung, Xiaomi, etc.)

price_usd: Retail price in USD ($)

rating: User satisfaction score (1.0 to 5.0)

camera_rating: Camera hardware and picture quality score

performance_rating: Processor, GPU, and speed score

cluster: Segment assigned by K-Means model (0, 1, 2, or 3)

**🧹 3. Preprocessing & Key EDA Findings**

Preprocessing Steps

Cleaning: Removed duplicate items and handled missing spec values.

Standardization: Scaled numerical values (price_usd, rating, camera_rating, performance_rating) using StandardScaler so all features carry equal weight in the models.

**Key EDA Findings**

Price vs. Performance: Hardware performance increases sharply up to $800, after which performance gains slow down significantly.

The Value Sweet Spot: Mid-range phones priced between $300 and $500 often receive user ratings equal to or higher than premium $1,000+ flagships.

Brand Leaders: Mid-market volume is dominated by high-rating value brands, while top-tier pricing is dominated by flagship series.

**🧠 4. Machine Learning Implementation** 

A. K-Means Clustering & The Elbow MethodModel Used.

B. Similarity Recommendation System

Model Used: NearestNeighbors (K-NN)

How It Works: Compares standardized phone features using Euclidean distance to instantly return the top 5 most similar phones in the dataset.

**📊 5. Cluster Breakdown & Market Segments**

The 4 market segments generated by the model are:

Cluster 0 — Budget / Entry-Level: Low price, basic features, high sales volume in cost-sensitive markets.

Cluster 1 — Premium Flagships: High price ($1,000+), top-tier camera and performance specs.

Cluster 2 — Mid-Range "Sweet Spot": Moderate price ($300–$500) with exceptionally high user satisfaction ratings.

Cluster 3 — Underperforming / Outdated Models: Low satisfaction ratings despite competitive spec sheets, often due to poor software optimization or reliability issues.

**📈 6. Future Business Insights**

Dynamic Pricing: Use cluster trends to adjust mid-range phone prices dynamically during retail sales.

E-Commerce Integration: Connect the K-NN recommendation logic to e-commerce product pages as a "Similar Alternatives" comparison box.

Inventory Control: Flag phones in Cluster 3 automatically to review supplier quality before stocking up.
